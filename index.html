Spatial Experience Dataset Curator

Nov 2026Data scienceCode on GitHub

Four open studies of how people find their way through spaces, and rate them, combined into one table of 6,513 trials.

  • Collected CC-BY datasets from Zenodo: a real library, two VR navigation experiments and street-safety ratings from Athens. I checked each licence before using it.
  • Defined one schema for every trial: participant, age group, environment, task, condition, time, errors, rating, plus spatial features and the source's DOI and licence on every row.
  • Wrote a Python pipeline that downloads each source, checks it against Zenodo's md5, maps it and validates it. 43 pytest tests check every mapping against the raw files.
What the checks found

One README's age codes contradicted the data's own "under 30" flag, so I mapped them one step down and wrote a test that compares them with that flag. The same source had 122 respondents, not the 129 its description gives. A library dataset marked 33 searches as successful while recording the wrong rack, side and shelf. All of it is written up in the data card, including what the combined data cannot be used for.

Noisy Defect Detection

Oct 2026Computer visionCode on GitHub

Median filtering raised pixel ROC-AUC from 0.86 to 0.95 at noise level 0.2.

  • Finds scratches, cracks and dents while training only on defect-free images, as on an inspection line where labelled failures are rare.
  • Compares a PatchCore-style k-NN detector from the literature with a simple per-pixel z-score baseline.
  • Scores each filter twice: on image quality (PSNR, SSIM) and on detection (ROC-AUC).
The surprise

The Wiener filter made the cleanest-looking images (best PSNR) but gave weaker detection than the median filter. A cleaner image was not a better input for the model. You can see the same effect in the demo above.

Python, SciPy, NumPy, pytest

On this synthetic data the simple z-score baseline stayed at 0.99 or higher at every noise level. My next step is to test both detectors on real MVTec AD images, which the code already loads.

LeaveBuddy

Nov 2026AutomationCode on GitHub

An employee types "I want 2 days off next week" in Teams, and the request reaches their manager as an approval.

  • Copilot Studio agent with two topics: one collects and checks leave type, dates, days and reason before asking for confirmation, the other lists the employee's latest requests.
  • A Power Automate flow saves each request to a SharePoint list, finds the manager in Entra ID and starts a Teams approval.
  • When the manager answers, the list is updated and the employee gets the result as a Teams message.
The design problem

Copilot Studio waits only about 100 seconds for a flow, but a manager can take days. So the flow answers the agent straight away with a request number, keeps running in the background while it waits for the approval, and sends the result to the employee later as a separate Teams message.

InterviewIQ

Mar - Jun 2026LLM & GenAILive demoCode

Upload your resume, ask an interview question, and get an answer that only uses your real experience.

  • RAG pipeline: PDF parsing, chunking, embeddings and FAISS retrieval for Llama 3.3 70B, with prompt rules that forbid invented facts.
  • Two modes: a fast single-call answer, or three agents (Researcher, Writer, Critic) built as LangChain prompt chains.
  • FastAPI backend on Render, React and Tailwind frontend on Vercel. I built every part myself.
What I measured

I ran both modes on 8 standard interview questions and tracked the runs in MLflow. The agents took 7.4 seconds per answer, the single call 3.2. The Critic gave an average of 8.9 out of 10, but I don't lean on that number, because the same model grades its own answers.

F1 Podium Predictor

Jul 2026Data scienceCode on GitHub

No model beat the simple baseline on F1 (0.701). I wrote that down instead of hiding it.

  • Built a 3,458-row dataset from an external API, with pagination and rate-limit handling.
  • Wrote an automated test that fails if the data pipeline leaks future information.
  • Compared logistic regression, random forest and XGBoost with temporal cross-validation and metrics for imbalanced classes.
What still worked

The random forest improved PR-AUC from 0.687 to 0.706, so it ranks podium finishers a little better even though its F1 does not beat the baseline. SHAP also showed me that one feature was confounded.

Inside a Neural Network

Oct 2025 - Feb 2026Deep learningM.Sc. projectCode on GitHub

Removing the 50 largest weights from a trained CNN changed accuracy by only 0.03 percentage points.

  • Analysed how a CNN trained in PyTorch to 98.98% test accuracy on MNIST reaches its decisions.
  • Used forward hooks to record the activations of every layer.
  • Ran controlled ablations on 64 convolutional channels and 128 neurons across 10,000 test images.
Why it matters

Big weights look important, but the ablations showed that weight magnitude is a poor proxy for how much a part of the network actually contributes to its decisions.
